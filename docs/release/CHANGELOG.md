# Release notes

Generated by Changesets (`pnpm changeset:version`). Newest first. The task-level log is the root `CHANGELOG.md`.

## 0.7.4

### Patch Changes

- c453b7e: `Chart` reference line texts with `labelPosition: 'auto'` no longer cover the highlight text ("Hoje"), bars or the line in narrow charts (GAP-057, reopened). When no place along the line is clear and the end margin would be too wide, the text goes to a row above the plot after a short sample of its line, like a legend; the plot gets shorter by that row. The accessible name, description and hidden table are unchanged. Charts whose text was already clear look the same.

## 0.7.3

### Patch Changes

- e83f2db: `Chart` reference line texts no longer print over the highlight text ("Today"), the bars, the line or each other (GAP-057). The text stays at the end of the line when that place is clear; otherwise it moves to the start, below the line, or outside the plot on the end side (the plot gets narrower by the width of the text). New optional `labelPosition` (`'auto' | 'end' | 'start'`, default `'auto'`) on each reference line pins the side. The accessible name, description and hidden table are unchanged. In a right-to-left page the reference texts are no longer pushed off the end of the chart. Charts whose reference text covered marks look different; charts where it was clear are unchanged.

## 0.7.0

### Breaking changes

Pre-1.0 minors may break. Check these when upgrading to 0.7.0:

- `Sidebar` status without `tone` is now grey instead of green; pass `tone: 'success'` to keep green. `SidebarStatus.tone` also gained `neutral` (GAP-050).
- `ChatMessage.id` is optional and `ChoiceTiles` `meta` is a `ReactNode` instead of a `string` (GAP-048).
- `DividerVariant` gained `dashed` (GAP-042); exhaustive `switch` statements need the new case.
- Layout: `Tabs` is 1 px shorter with the underline on the divider (GAP-037); `Stepper` switches to the compact form at a wider container (GAP-047); `LedgerList` stacks the date under the title in containers 480 px or narrower (GAP-055).

Entries carrying a `**Breaking:**` marker in the root `CHANGELOG.md` have `breaking: true` in `loui-ds/changes.json`.

### Minor Changes

- a350cea: New `CardLink` and `AddCard` (ADR-0011, GAP-018); `CurrencyInput` `entryMode="amount"` and `parseCurrencyAmount` (GAP-054); `Chart` notes, reference lines and `tickEvery` (GAP-019); `Legend` shares, `ProportionBar` columns and `total` (GAP-020); `MatrixGrid` async toggles and sticky headers (GAP-029); `Divider` `dashed` and the paper `Card` entry point (GAP-042); `Button` `shortcut` with `aria-keyshortcuts` (GAP-045); `ChatPanel`, `ChoiceTiles`, `ScrollArea` additions and the `PasswordField` recipe (GAP-048). Visual changes: `Tabs` drops a 1 px overflow (GAP-037), `Stepper` with many steps switches to the compact form earlier (GAP-047), `LedgerList` stacks the date under the title in narrow containers (GAP-055).
- a032255: `Combobox` option `leading`, `onCreate` and `fullWidth` with the `CreateOnTheFly` recipe (GAP-034); `CurrencyInput` `fullWidth`, documented events and the `InlinePriceEdit` recipe (GAP-030); `DataTable` per-column minimum widths and an empty state that does not scroll (GAP-051); toasts stay clear of an open `Sheet` (GAP-052); `groupKey` on `useUndoable` and `toastWithUndo` replaces the previous toast (GAP-053). Behaviour change: a `Sidebar` status without `tone` is now neutral (grey) instead of green; pass `tone: 'success'` to keep it green (GAP-050).

## 0.3.0

### Minor Changes

- 5915564: `Combobox` gets `selectFirstOnEnter` (default `false`): `Enter` with no option highlighted selects the first enabled filtered option instead of dropping the typed text. The `filter` function now receives the whole option as a third argument, `(label, query, option)`, so options can be searched by a code or `meta`; two-argument filters and the accent-insensitive default keep working (GAP-033).
- 079f28b: `Form` now types and documents `id`, `onKeyDown`, `onKeyUp`, `onFocus` and `onBlur`, so a submit button elsewhere (such as a `Sheet` footer) can target it with `form="id"`. New `SheetForm` recipe: a form in a `Sheet` submitted natively from the footer. (GAP-023)

### Patch Changes

- 811f947: Keep the `Button` label visible (dimmed with the new `--ds-button-pending-label-opacity` token) next to the spinner while `isPending`, instead of hiding it (GAP-014). The width is still stable.
- 5915564: A consumer `onKeyDown` on `Input`, `CurrencyInput`, `Textarea` and `SearchInput` no longer swallows every key: unless the handler calls `event.preventDefault()`, the key keeps bubbling so `useHotkeys(..., { allowInEditable: true })` shortcuts (F9, F2, N) still fire while the field has focus. `Combobox` follows the same rule. Documented in the field pages and `docs/architecture/hotkeys.md`, with a keyboard test (GAP-035).
- 78c9e6e: `Stack`, `Inline` and `Grid` `gap` now accept the space key as a number (`gap={4}`) or as its string form (`gap="4"`), matching the generated docs and the AI manifest. The manifest generator prints numeric literal types bare (`1 | 2 | 3`) instead of quoting them, and a new test type-checks every documented prop value (GAP-021). New exported type `SpaceValue`.
- 8f4c2e7: `StatCard` accepts a computed `StatCardTone` (for example `tone={flag ? 'warning' : 'neutral'}`) together with `note` or `trend`. A literal non-neutral tone without `note` or `trend` is still a type error. (GAP-032)

## 0.1.0

### Minor Changes

- 98d3f52: First tagged version of Loui DS (0.1.0): dark-only design tokens (`--ds-*`, DTCG source, Terrazzo build), 100+ accessible React 19 components on React Aria Components (`@loui/ds`), domain patterns (`@loui/ds/patterns`), layout and typography primitives, `DSProvider` with English and pt-BR catalogs, keyboard-first infrastructure (`useHotkeys`, `CommandPalette`), `styles.css` with self-hosted Geist fonts, per-module `'use client'` directives for React Server Components, a generated `manifest.json`, `llms.txt` and an MCP server for agents. All components are `experimental` until they graduate under the lifecycle in `docs/release/lifecycle.md`.
- New components: `Banner`, `Stepper`, `Timeline`, `Drawer` (non-modal side panel), `Tour` (onboarding coachmarks), `StackedBar` and `Legend`. New AI patterns in `@loui/ds/patterns`: `ToolCallStep`/`ToolCallList`, `SourceList`/`Citation` and `ResponseFeedback`, plus a `MarkdownMessage` recipe for `ChatPanel.renderContent`. Curated icons `CopyIcon`, `RefreshIcon`, `ThumbsUpIcon`, `ThumbsDownIcon`. A Tokens Studio export (`tokens-studio/tokens.json`) keeps Figma in sync with the CSS tokens.

### Patch Changes

- 602e50f: TopBar: the title wins the space on narrow screens (content next to it wraps to a second line before the title truncates). The last raw spacing values in Code, LedgerList, MatrixGrid and StatusSteps are now component tokens.
- 35c5e36: Export `useUndoable` and its types from the package root. A `Kbd` inside a primary or danger-solid `Button` now reads `--ds-kbd-fg` and `--ds-kbd-border` (new tokens), so the hint keeps 4.5:1 contrast on the filled button. `FormErrorSummary` names a required `Select` by its label instead of its field name. The `ToastRegion` landmark is now named "Toast notifications" (pt-BR: "Notificações temporárias") so it no longer clashes with a Card titled "Notifications"; apps that look the region up by its old name need to update the query. The manifest gains a `recipes` list.
