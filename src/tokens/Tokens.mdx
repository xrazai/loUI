# Design tokens

The complete reference. Every value below is generated from `src/tokens/generated/tokens.json`, which Terrazzo builds from the DTCG sources in `src/tokens/*.json`, so this page cannot drift from the code. Contrast ratios are computed from the resolved values (WCAG 2.2 relative luminance); translucent tokens are flattened over each surface.

For when and how to use them, read the usage pages: [Color](?path=/docs/foundations-color--docs), [Typography](?path=/docs/foundations-typography--docs), [Spacing, sizing and radius](?path=/docs/foundations-spacing-sizing-and-radius--docs), [States and interaction](?path=/docs/foundations-states-and-interaction--docs) and [Motion, layering and iconography](?path=/docs/foundations-motion-layering-and-iconography--docs). The rules behind them are in the [Principles](?path=/docs/guides-principles--docs) guide.

Every CSS variable is prefixed `--ds-`. Components use **semantic** tokens only; the primitive palette exists to define them.

## Colors: semantic

Contrast columns show the ratio of each token as a foreground (or border) against the three surfaces it is used on. Text needs 4.5:1 (WCAG 1.4.3); control boundaries and graphics need 3:1 (1.4.11). Backgrounds, tints and decorative lines have no ratio requirement and show n/a.

## Typography

Weights: 400, 500, 600 (sans), 400, 500 (mono). **The minimum font size is 11.5px** (`--ds-fs-caption`). Use `font-variant-numeric: tabular-nums` (the `.ds-tabular-nums` utility) on every numeric role.
