# Design tokens

Every value below is generated from `src/tokens/generated/tokens.json`, which Terrazzo builds from the DTCG sources in `src/tokens/*.json`. Contrast ratios are computed from the resolved values (WCAG 2.2 relative luminance); translucent tokens are flattened over each surface.

Every CSS variable is prefixed `--ds-`. Components use **semantic** tokens only; the primitive palette exists to define them.

## Principles

1. **One accent.** `--ds-accent` is for focus, selection, links and open states. Never a button fill or a large area.
2. **Ink for action.** The primary button is light on dark (`--ds-primary-bg`). One primary action per screen.
3. **Borders first.** Hierarchy comes from surface plus border. Shadows only on overlays.

Move one surface layer at a time: `bg-canvas`, `bg`, `surface`, `surface-raised`, `surface-hover`. Do not skip layers.

## Colors: semantic

Contrast columns show the ratio of each token as a foreground (or border) against the three surfaces it is used on. Text needs 4.5:1 (WCAG 1.4.3); control boundaries and graphics need 3:1 (1.4.11). Backgrounds, tints and decorative lines have no ratio requirement and show n/a.

## Typography

Geist for the interface, Geist Mono for numbers, codes and shortcuts. Weights: 400, 500, 600 (sans), 400, 500 (mono). **The minimum font size is 11.5px** (`--ds-fs-caption`); nothing in the system may be smaller. Use `font-variant-numeric: tabular-nums` (the `.ds-tabular-nums` utility) on every numeric role.
