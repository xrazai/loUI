# Changelog

All notable changes to this project are documented here. Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versioning will follow [Semantic Versioning](https://semver.org/) once the first release is cut.

**Workflow:** when a task from [TODO.md](TODO.md) is finished, remove it from the TODO and add an entry below under `[Unreleased]` (keeping the task ID). If an upgrade can change what a consumer sees or compiles (a default, a layout or line-break change, a widened output type, a removed or renamed API), end the entry with `**Breaking:** <what the consumer does>`; `changes.json` turns the marker into `breaking: true` (see [versioning](docs/release/versioning.md)). On release, `[Unreleased]` is renamed to the version and date by the release process.

## [0.7.4] - 2026-11-04
### Fixed

- **GAP-057** (2026-11-04, reopened after 0.7.3) `Chart` reference texts with `labelPosition: 'auto'` no longer cover anything in narrow charts. The ERP report in an 800 px window (chart box about 470 px, 30 days) still printed "Média por dia aberto R$ 1.572,23" over "Hoje": the end margin was skipped (over 40% of the width) and the text stayed at the least-overlapping place inside. New last step: a row above the plot, end-aligned, after a short sample of the line in its dash pattern; the plot gives up the row height, several texts sit side by side and wrap. The end margin is now also rejected when a highlight text of the last point reaches into it. Text boxes use the measured caption metrics (12 px above the baseline, 4 below, was 9 and 3). New stories `ReferenceLabelTopRow` (470 px, pt-BR, closed Sundays, "Melhor" and "Hoje") and `ReferenceLabelReport800`; browser layout tests now cover 470, 800 and 1366 px, 30 and 90 points, bar and line, with that report data and checking ticks too. Baselines changed for `AverageLine`, `AverageAndTarget` and `AnnotatedRtl` (their texts grazed a bar or the line; now in the row).

## [0.7.3] - 2026-11-04
### Fixed

- **GAP-057** (2026-11-04) `Chart` reference line texts no longer overprint the highlight text, the bars, the line, note markers or each other, reported by the ERP (Reports, 30 and 90 days, at 800 and 1366 px). With the new default `labelPosition: 'auto'` the text keeps the end of the line, above it, when that is clear; otherwise it tries the start, then below the line, and when bars cross the line at both ends it is printed outside the plot on the end side, level with its line (the plot gives up the width of the text; skipped when that would take more than 40% of the width or hide category labels). `labelPosition: 'end' | 'start'` pins the side. Accessible name, description and hidden table unchanged. The chart SVG is now `direction: ltr`, so in a right-to-left page reference texts are no longer pushed off the end of the plot. New stories `ReferenceLabelAvoidsHighlight`, `ReferenceLabelOutside` and `ReferenceLabelPinned`; placement unit tests and browser layout tests (bar and line, 30 and 90 days, 800 and 1366 px) check that the text box intersects no bar, point, highlight or category text; `Chart.md` "Reference line labels". Baselines changed for `AverageLine` (text moved from over the Sat bar to the start) and `AnnotatedRtl` (texts were clipped).

## [0.7.0] - 2026-11-04
### Changed

- (2026-11-03) Size budgets: `patterns (ESM)` 37 → 39 kB (38.2 kB with `ColorOptionGroup`, `MatrixGrid` async toggles and `ChatPanel` keys) and `styles.css` 24 → 25 kB (24.3 kB with `CardLink`, `AddCard`, `SplitLayout`, `ColorField`, chart and legend rules). The growth comes from these new components; no deeper size audit was done.

### Added

- **GAP-018** (2026-11-03) New `CardLink` and `AddCard` (experimental), ADR-0011 (accepted by the owner): `Card` stays non-interactive. `CardLink` makes the whole card one real link (`href`) or button (`onPress`) through a stretched hit area on its title, which is the accessible name; description and meta are the accessible description; no nested interactive content (typed: no `children`, no `actions`); `target="_blank"` adds `rel` and a hidden "opens in a new tab". `AddCard` is the dashed "create new" tile with a plus icon and a verb + object label, stretching to the row height in a `Grid`.
- **GAP-054** (2026-11-03) `CurrencyInput` `entryMode="amount"` (opt-in; `cents` stays the default): digits are whole units and the decimal mark starts the fraction ("200" → 200.00, pt-BR "1.234,56" → 123456 minor units), still exact integers with no floating point. Plain text while focused (the value is selected on focus), full format on blur, `decimal` keyboard. New `parseCurrencyAmount` utility with property tests; "Typing modes" in `CurrencyInput.md` says when to use each; ADR-0006 amendment. The `InlinePriceEdit` recipe now uses the amount mode.
- **GAP-019** (2026-11-03) `Chart` `notes` by data index (diamond marker, shown in the active-point label, the hidden table and the announcement), `referenceLines` (`average` long dashes, `target` dash-dot, labelled in text, included in the description and a table footer, the y-domain grows to fit them), `tickEvery` to choose which axis labels show, and the `chartAverage` helper.
- **GAP-020** (2026-11-03) `Legend` `showShare` (with a numeric `amount` per item, `shareOf`, `shareDigits`; value and share in aligned columns), `StackedBar` `legendShare`, `ProportionBar` `legendColumns` (`share | value | count`), a stable `id` per segment shared with its legend item, and `total` for a "part of the whole" bar with a "Remaining" row.
- **GAP-029** (2026-11-03) `MatrixGrid`: `onToggle` may return a promise (pending cell with `aria-busy`, a spinner and a "saving" name, repeat toggles ignored; `onToggleError` plus a polite announcement on failure), sticky column and row headers with scroll padding, and the focused cell's row and column highlighted while the grid has focus. Keyboard contract unchanged.
- **GAP-031** (2026-11-03) Verified, not a bug: `Sheet` focuses an `autoFocus` field on keyboard, pointer, scripted `click()` and controlled opens (with and without a trigger). Regression tests and an "Initial focus" section in `Sheet.md`.
- **GAP-037** (2026-11-03) `Tabs` no longer shows a vertical scrollbar: the tab's `-1px` bottom margin overflowed the list by 1 px; the bottom padding now subtracts the divider width (new `tabs.divider-width` token). The active underline sits on the divider instead of over it. **Breaking:** the tab list is 1 px shorter and the underline moved 1 px up; re-check pixel-exact layouts and screenshots that include `Tabs`.
- **GAP-042** (2026-11-03) `Divider` `variant="dashed"` (receipt total line; `CanvasText` in forced colours, follows the paper scope). `Card.md` documents `<Card data-theme="paper">` as the paper entry point with a tested receipt preview (contrast checked) and the list of paper-safe components. **Breaking:** `DividerVariant` is wider (`dashed`); an exhaustive `switch` or `Record<DividerVariant, …>` needs the new case.
- **GAP-045** (2026-11-03) A `Kbd` inside a `Button` no longer doubles the accessible name: buttons hide nested `Kbd` from the name, and the new `Button` `shortcut` prop renders the keys and sets `aria-keyshortcuts` once (`Control+K`, `Meta+K` on Apple).
- **GAP-046** (2026-11-03) Not reproduced in the design system: `useHotkeys` ignores Escape only inside an open dialog or menu (role-based), and Escape fires again once a `ConfirmDialog` closes and focus is back on its trigger. Regression test added; if the app still sees it, the trigger is probably a menu or popover trigger and needs a repro.
- **GAP-047** (2026-11-03) `Stepper` labels never break inside a word and clip after two lines; the compact "Step N of M" form starts at a wider container the more steps there are (480 px by default, 600 for 6, 720 for 7–8, 800 for 9+). **Breaking:** with 5 or more steps the compact form appears at a wider container than before; check `Stepper` in narrow panels and update screenshots.
- **GAP-048** (2026-11-03) `ChatPanel` takes `{ role, content }` messages without ids (`getKey`, documented default), `busyLabel` and `busyIndicator`; `ChoiceTiles` `meta` accepts a node and a second line `detail` (the radio's description); `ScrollArea` `maxBlockSize`; new `PasswordField` recipe (show/hide toggle, `current-password`/`new-password`, paste allowed per WCAG 3.3.8). **Breaking:** `ChatMessage.id` is now optional, so code that reads `message.id` as a `string` needs `message.id ?? key`; `ChoiceTiles` `meta` went from `string` to `ReactNode`, so code that assigns or reads it as a string needs a type check.
- **GAP-055** (2026-11-03) `LedgerList` in a container 480 px or narrower moves the date under the title, so titles keep a readable width with edit and delete buttons; amounts stay aligned and the reading order is unchanged. **Breaking:** the narrow layout is new; check screenshots and any CSS that targeted the date column of `LedgerList`.
- **GAP-034** (2026-11-03) `Combobox` options take a decorative `leading` node (a `Swatch`, `Icon` or `Avatar`; the option's name stays its text), repeated at the start of the input while the selected label is shown. `onCreate(text)` adds a "Create “text”" row (pt-BR "Criar “…”", `createOption` message) when the typed text matches no option; choosing it never calls `onChange` and does not replace the typed text. `fullWidth` as on `Input`. New recipe `CreateOnTheFly` (create, select the new item, toast with Undo).
- **GAP-030** (2026-11-03) `CurrencyInput` documents `placeholder`, `onKeyDown`, `onFocus` and `onBlur` (an "Events" section: handler composition, `onChange` before `onBlur`). The placeholder already shows while the value is `null`, focused or not, until the first digit (now tested; `0` is a value). `fullWidth` as on `Input`. New recipe `InlinePriceEdit`: a price that reads as text and edits in place (Enter or blur confirms, Esc cancels and restores, empty inherits, saved value announced politely). The typing model is unchanged (GAP-054).
- **GAP-050** (2026-11-03) `Sidebar` status `tone` adds `neutral` (grey dot, `--ds-text-3`) and uses it when `tone` is omitted. **Breaking:** a status without `tone` was green and is now grey; pass `tone: 'success'` to keep it green. `SidebarStatus.tone` is also wider (`neutral`), so an exhaustive `switch` on it needs the new case.
- **GAP-051** (2026-11-03) `DataTable`: an empty table no longer scrolls sideways (the table minimum width is dropped while there are no rows; the header stays). Each flexible column now gets its own `minWidth` plus an equal share of the remaining space, and the table minimum is the sum of the column minimums, instead of every flexible column inheriting the largest `minWidth` (a `cqw` container measure, because Chrome's fixed table layout treats `calc()` with `%` as `auto`). Use px or rem for `width`/`minWidth` in these tables; documented with an example.
- **GAP-052** (2026-11-03) Toasts no longer cover an open `Sheet`'s footer: while a sheet is open the toast region centres in the free space beside it, and below 768 px (full-width sheet) it moves to the top, under the sheet header. CSS only (`Sheet` marks its modal with `data-ds-sheet`, the region reads it with `:root:has(…)`, a scoped exception to the no-global-selector rule that keeps it SSR-safe); `--ds-toast-clearance` follows the region. Keyboard access, pause on hover/focus and reduced motion are unchanged.
- **GAP-053** (2026-11-03) `groupKey` on `useUndoable` actions and on `toastWithUndo`: a new action with the same key commits the previous one and replaces its toast, so four quick toggles leave one Undo toast for the last change. Different or missing keys still stack. Not "Undo 4 changes": grouped actions can touch different records in any order, so one Undo could not reverse them safely.

## [0.6.0] - 2026-11-03
### Added

- **GAP-024** (2026-11-03) New `ColorField` (experimental): wraps React Aria `ColorField` in hex mode with the `Input` field anatomy (label, description, `descriptionTone`, error, sizes, `fullWidth`) and a decorative leading `Swatch` (empty when there is no value). Hex in Geist Mono, uppercase; `#abc` normalises to `#AABBCC` on blur or Enter, non-colours revert, `↑/↓` step the value. `value`/`defaultValue` take `#RRGGBB` or a `Color`, `onChange` gets a `Color` or `null` (`color?.toString('hex')` for the string). Default error "Enter a colour as #RRGGBB." (pt-BR included). Design note: wrapping RAC needs no ADR (ADR-0001, no new dependency); a picker is a later task.
- **GAP-026** (2026-11-03) New `ColorOptionGroup` pattern (experimental) on React Aria `ToggleButtonGroup`: a named group of `ColorOption`s with `value`/`defaultValue`/`onChange(string[])`, `selectionMode` (`multiple` by default, `single` renders a radio group), group and per-option `isDisabled`, `description`, `isInvalid` + `errorMessage` through `ErrorText` linked with `aria-describedby`, and `columns`. One tab stop, arrow keys stop at the ends.
- **GAP-038** (2026-11-03) New `SplitLayout` (experimental): main content plus a fixed-width side panel (`asideWidth` `sm | md | lg`, `md` = the AppShell detail width), `asidePosition` (logical), `gap`, `sticky` (sticks below an offset token with its own scroll, focusable when it scrolls) and `collapseBelow` (`sm | md | lg | never`, by the layout's own width). The panel is a named `aside` only with `asideLabel`. `fullWidth` on `Input`, `Textarea`, `Select`, `SearchInput`, `NumberField`, `DatePicker` and `ColorField` lets a field take the free space of an `Inline` row (`Combobox` and `CurrencyInput` follow with GAP-034 and GAP-030). `AppShell` `detail={null}`, `false` or a component that renders `null` no longer leaves an empty 360 px column.
- **GAP-049** (2026-11-03) `LedgerList` rows can be edited: `onEdit(entry)` on the list and `isEditable` per entry render an "Edit entry …" pencil button before delete, in a fixed actions column so amounts stay aligned across rows with both, one or no button. Stories show editing in a `Sheet` (focus returns to the edit button) and inline with `CurrencyInput`. `LedgerList` is now `stable`.
- **GAP-017** (2026-11-03) `ActionList` rows can carry a checkbox: `selectionMode` (`none | multiple`), `selectedKeys`, `defaultSelectedKeys` and `onSelectionChange`, with the DS `Checkbox` on the leading side, named "Select <row text>". `Space` and the checkbox toggle; `Enter` and a click on the row content still run `onAction`, also while rows are selected (React Aria would otherwise turn the row into a pure toggle; `ActionList` routes the row action itself in that one combination, tested). A task row (module label plus a `DueIndicator` or `Badge`) fits the existing `meta` slot. The undo pattern for reversible toggles (`toastWithUndo`) is documented with a story. In a list 480 px wide or narrower, `meta` moves under the title (container query), so titles no longer shrink to a few characters; existing ActionList baselines changed for that reason. Design note in `ActionList.md`: extend `ActionList`, no separate `CheckList`. **Breaking:** the `meta` position changes at 480 px or narrower; check screenshots and CSS that assumed `meta` stays on the row's right side.
- **GAP-015** (2026-11-03) `ActionListItem.isDone`: the title shows in `--ds-text-3` with a line-through (kept in forced colours) and a visually hidden "Done" ("Concluído") follows it, so the state is never decoration alone.
- **GAP-016** (2026-11-03) `DueIndicator` takes `date` and `today` as `ISODate`, `Date` or an ISO date-time string, normalised to the local calendar day by the new `toCalendarDay` utility (a plain `YYYY-MM-DD` is never shifted by time zone; malformed values still throw in development). A free-text form `label` + `tone` (`neutral | accent | success | warning | danger`) renders the same dot and text without a date; TypeScript requires one form or the other. `paidDate` shows "Paid Oct 30" through the `paidOn(date)` message (pt-BR "Pagamento em …", no gender agreement). `DueIndicatorProps` is now a union type. **Breaking:** `DueIndicatorProps` is now a union (date form or `label` + `tone` form); code that extends or indexes it as an interface (`interface X extends DueIndicatorProps`, `Omit`, `keyof`) needs a type check.
- **GAP-025** (2026-11-03) `Text` `tone` adds `success`, `warning` and `danger` (the same signal tokens as `Description`; the words still carry the meaning). New `ErrorText`: the `FieldError` look outside a React Aria field, with an `id` for `aria-describedby` on a group, nothing rendered when empty, and an optional `announce` (`role="alert"`) for errors that appear without a focus move. `Field.md` compares `FieldError`, `ErrorText` and `Alert`. **Breaking:** `TextTone` is wider (`success`, `warning`, `danger`); an exhaustive `switch` or `Record<TextTone, …>` in your code needs the new cases.
- **GAP-022** (2026-11-03) A controlled `Sheet` or `Dialog` (and so `ConfirmDialog`) without `trigger` no longer logs "A PressResponder was rendered without a pressable child": the `ModalOverlay` gets the open state directly and `DialogTrigger` is used only with a trigger. Console-clean tests cover controlled open, Escape and focus return.
