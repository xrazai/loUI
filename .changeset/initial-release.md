First tagged version of Loui DS (0.1.0): dark-only design tokens (`--ds-*`, DTCG source, Terrazzo build), 70+ accessible React 19 components on React Aria Components (`@loui/ds`), domain patterns (`@loui/ds/patterns`), layout and typography primitives, `DSProvider` with English and pt-BR catalogs, keyboard-first infrastructure (`useHotkeys`, `CommandPalette`), `styles.css` with self-hosted Geist fonts, per-module `'use client'` directives for React Server Components, a generated `manifest.json`, `llms.txt` and an MCP server for agents. All components are `experimental` until they graduate under the lifecycle in `docs/release/lifecycle.md`.
